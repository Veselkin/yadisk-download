# yadisk-download

Скачивание публичных папок с Яндекс Диска по ссылке — без авторизации, без сторонних библиотек, без платной подписки.

Актуально после того, как Яндекс [отключил бесплатную синхронизацию в десктопном приложении](https://habr.com/ru/news/1042970/) с 3 июня 2026 года.

## Возможности

- Скачивает всю папку рекурсивно, сохраняя структуру каталогов
- Показывает прогресс каждого файла
- Пропускает уже скачанные файлы (проверка по размеру) — можно прерывать и продолжать
- Работает с публичными ссылками вида `https://disk.yandex.ru/d/...`
- Только стандартная библиотека Python — ничего устанавливать не нужно

## Требования

- Python 3.8+

## Использование

```bash
python yadisk_download.py <ссылка>
```

Файлы сохранятся в папку `downloaded` рядом со скриптом.

Можно указать свою папку:

```bash
python yadisk_download.py <ссылка> C:\MyFiles
```

### Пример

```
> python yadisk_download.py https://disk.yandex.ru/d/XXXXXXXXXXX D:\Загрузки

Получаю список файлов...
Найдено файлов: 295, общий размер: 1842.3 МБ

[1/295] Фото/01.jpg
  100% (2.1 MB)
[2/295] Фото/02.jpg
  пропускаю (уже скачан)
...
Готово! Файлы сохранены в: D:\Загрузки
```

## Как это работает

Скрипт использует официальное публичное API Яндекс Диска (`cloud-api.yandex.net`) — авторизация не требуется. Папка обходится рекурсивно, каждый файл скачивается по отдельной прямой ссылке.

## Ограничения

- Работает только с **публичными** ссылками (`/d/...`). Файлы из собственного диска так не скачать
- Скорость ограничена самим Яндексом
