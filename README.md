# yadisk-download

Скачивание публичных папок с Яндекс Диска по ссылке — без авторизации, без сторонних библиотек, без платной подписки.

Актуально после того, как Яндекс [отключил бесплатную синхронизацию в десктопном приложении](https://habr.com/ru/news/1042970/) с 3 июня 2026 года.

## Возможности

- Скачивает всю папку рекурсивно, сохраняя структуру каталогов
- Показывает прогресс каждого файла
- Пропускает уже скачанные файлы (проверка по размеру) — можно прерывать и продолжать
- Автоматически повторяет запрос при таймаутах и сетевых сбоях (с нарастающей паузой)
- Работает с публичными ссылками вида `https://disk.yandex.ru/d/... и https://disk.yandex.ru/i/...`
- Только стандартная библиотека Python — ничего дополнительно устанавливать не нужно

## Требования

- Python 3.8+

## Использование

```bash
python yadisk_download.py <ссылка>
```

Файлы сохранятся в папку `downloaded` рядом со скриптом.

Можно указать свою папку:

```bash
python yadisk_download.py <ссылка> C:\MyFiles
```

### Пример


## Как это работает

Скрипт использует официальное публичное API Яндекс Диска (`cloud-api.yandex.net`) — авторизация не требуется. Папка обходится рекурсивно, каждый файл скачивается по отдельной прямой ссылке. При таймауте или обрыве соединения запрос повторяется автоматически (до 5 попыток для запросов списка, до 3 — для скачивания файла).

## Ограничения

- Работает только с **публичными** ссылками (`/d/... для директорий и файлов, представляющих из себя контейнеры и /i/... для файлов`). 
- Файлы из собственного диска можно скачать, если поделиться ссылкой на необходимый файл или каталог.
- Скорость ограничевается только Яндексом и вашим каналом.
